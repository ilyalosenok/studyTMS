1. Создать в virualbox (или другом гипервизоре) виртуальную машину с примонтированным образом ubuntu (серверную)
2. Установить операционную систему
Установил virtualbox, в ней создал ВМ с серверной ubuntu 24.04.3
3. Обновите предустановленные пакеты
sudo apt update && sudo apt upgrade
4. НАстроить удаленный доступ по ssh ssh
    Проверьте что установлен необходимый пакет и запустите сервис (по умолчанию должен предустанавливаться)
sudo apt install -y openssh-server
sudo systemctl enable ssh
sudo systemctl start ssh
5. Сгенерируйте пару ключей
ssh-keygen -t ed25519 -C "ilyaya90@mail.ru"
6. Скопируйте ключ на удаленный сервер (попробуйте найти куда можно скопировать самостоятельно ключ что бы он был принят системой)
ssh-copy-id -i /home/ilyalosenok/.ssh/lab3.pub ilyalosenok@ilyalosenok
7. Выполните команды, что они выводят, как можно использовать вывод упомянутых команды

cat /etc/os-release - выводит содержимое файла /etc/os-release, который содержит информацию об ОС.

lsb_release -a - тображает информацию об используемом дистрибутиве и соответствии стандарту LSB, а так же версию ubuntu.

uname -m - выводит сведения о системе.

uname -a выводит сведения об имени сервера и версии ядра.

free -h - выводит информацию об использовании системной памяти в читаемом формате

cat /proc/meminfo | grep MemTotal - выводит общий объем физической оперативной памяти, доступной ОС.

lscpu - собирает и отображает подробную информацию об архитектуре центрального процессора, считывая данные из /proc/cpuinfo и sysfs. Она выводит такие данные, как количество ядер, потоков, сокетов, модель, частоту, объем кэш-памяти, семейство, а также флаги виртуализации и уязвимости.

cat /proc/cpuinfo | grep "model name" - выводит название модели и частоту установленного процессора.
